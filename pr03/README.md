## Описание работы
В данной работе реализован пайплайн предобработки данных с использованием `ColumnTransformer` и `Pipeline` из `scikit-learn`.

### Основные моменты:
1. **Защита от утечки данных (Data Leakage):** Разделение на `train` и `test` выполнено до всех этапов вычисления статистик.
2. **Числовые признаки:** Пропуски заполняются медианой (`SimpleImputer`), после чего применяется масштабирование (`StandardScaler`).
3. **Категориальные признаки:** Пропуски заполняются значением `'unknown'`, категориальные столбцы кодируются через `OneHotEncoder(handle_unknown='ignore')`.
