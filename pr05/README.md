## Описание работы
Построена модель логистической регрессии для прогнозирования оттока клиентов (моделируемые данные). 
Реализован подбор порога классификации с учетом бизнес-задачи (FN обходится дороже, чем FP). Построены матрицы ошибок, ROC- и PR-кривые. Произведено сравнение метрик (Precision, Recall, F1) для стандартного порога 0.5 и адаптированного порога 0.3.
